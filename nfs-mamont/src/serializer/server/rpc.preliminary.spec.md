## 2. Mechanics

This module implements the serialization logic for the ONC RPC `OpaqueAuth` structure, converting it from a Rust representation into the XDR wire format.

Intent:
- To provide a specific implementation for encoding RPC authentication credentials according to the ONC RPC standard.
- To ensure that the serialization of the authentication body respects the maximum size constraints defined by the protocol.

Inputs:
- `dest`: A mutable reference to a type implementing the `Write` trait, acting as the byte sink.
- `data`: An instance of `OpaqueAuth` containing the authentication flavor and the opaque body bytes.

Outputs:
- `io::Result<()>`: Indicates successful completion of the write operation or contains an I/O error.

Steps:
1. Extract the `flavor` field from the input `data`.
2. Invoke the `variant` helper function to serialize the `flavor` (an enum) into its integer discriminant representation and write it to `dest`.
3. Invoke the `vec_max_size` helper function to serialize the `body` field (a byte vector) into a length-prefixed byte array, enforcing `MAX_AUTH_SIZE` as the upper limit, and write it to `dest`.

Edge Cases:
- If the `body` length exceeds `MAX_AUTH_SIZE`, the `vec_max_size` function is expected to return an error, preventing the serialization of invalid protocol data.

Complexity:
- Time: O(N), where N is the length of the `body` vector, as the function must write each byte.
- Space: O(1) auxiliary space (excluding the output buffer).

Determinism:
- Deterministic. Given the same `OpaqueAuth` input, the sequence of bytes written to `dest` is identical.

## 7. Overview

This module is used in order to serialize the `OpaqueAuth` structure, which represents authentication credentials in the ONC RPC protocol, into the standardized XDR byte format required for network transmission.

This system contains a layered serialization architecture where the `nfs_mamont::serializer` module provides generic XDR primitives (writing integers, variable-length arrays), and the `nfs_mamont::rpc` module defines the semantic types (like `OpaqueAuth`). The current module bridges these two layers by composing the generic primitives to implement the specific serialization logic for the RPC authentication structure.

A typical usage scenario of the system involves preparing an RPC message for transmission over the network. When the message requires authentication data, the system constructs an `OpaqueAuth` struct. The `auth` function from this module is then called with a network stream as the destination. It ensures the `flavor` is written as a discriminant and the `body` is written as a bounded byte array, strictly adhering to the `MAX_AUTH_SIZE` limit defined by the RPC specification.

Inside the system, the following things happen and they use:
- **Protocol Encoding**: Uses `variant` to convert the `AuthFlavor` enum into a wire-format integer.
- **Constraint Enforcement**: Uses `vec_max_size` to write the variable-length body while validating that it does not exceed the protocol-defined maximum size of 400 bytes.
- **Stream Writing**: Uses the `std::io::Write` trait to abstract the destination of the serialized bytes, allowing the logic to work with buffers, sockets, or files.
